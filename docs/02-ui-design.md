# 渡口 Harbor · UI 设计

> 配套原型：[`mockup/index.html`](../mockup/index.html)（可在浏览器打开，9 个屏幕可切换、可交互）  
> 窗口基准尺寸：**1160 × 740**（最小 1024 × 680）；内容按 1x 设计，支持 125% / 150% 系统缩放。

---

## 1. 设计目标

1. **一眼知道当前角色与状态**：源端在共享什么、服务是否在跑；目的端连的是谁、传到哪一步。
2. **信息密度接近原生工具**：不堆大卡片和插画，关键数字（连接码、速度、剩余时间、文件数）优先。
3. **危险操作有摩擦**：停止服务、镜像删除、撤销信任都要明确后果，而不是一个静默开关。
4. **安静**：界面以暖中性色为主，只有状态色（进行中/警告/错误）和角色色出现饱和度。
5. **可键盘操作**：所有弹窗可 Tab 循环、Esc 关闭；主流程有快捷键。

## 2. 设计语言

### 2.1 色彩

| Token | 值 | 用途 |
| --- | --- | --- |
| `--paper` | `#F4F1EA` | 应用底色（暖纸色） |
| `--panel` | `#FFFFFF` | 卡片、列表、弹窗 |
| `--panel-sub` | `#FAF8F3` | 侧栏、标题栏、表头 |
| `--ink` | `#191B1E` | 主文字 |
| `--ink-2` | `#4C5157` | 次要文字 |
| `--ink-3` | `#7B8087` | 辅助说明、占位符 |
| `--line` | `#E6E2D9` | 1px 分隔线、卡片描边 |
| `--line-soft` | `#EFECE5` | 列表内分隔 |
| `--jade` | `#0E6B58` | 品牌色、源端主操作、进度 |
| `--jade-soft` | `#E7F1ED` | 源端选中态、徽标 |
| `--navy` | `#2B4E88` | 目的端主操作 |
| `--navy-soft` | `#E9EEF7` | 目的端选中态 |
| `--amber` | `#A4690F` | 校验中、警示 |
| `--red` | `#A6403A` | 失败、危险操作 |

规则：源端主按钮用玉青，目的端用靛蓝；角色色只用于主操作、选中态和模式徽标，不用作大面积背景。状态色（琥珀/红）只表达状态，不做装饰。

### 2.2 字体

```
西文/数字: -apple-system, "SF Pro Text", "Segoe UI Variable", "Inter", system-ui
中文:      "PingFang SC", "Microsoft YaHei UI", "Noto Sans CJK SC"
等宽:      "SF Mono", "Cascadia Mono", "JetBrains Mono", ui-monospace
```

| 层级 | 字号/行高 | 字重 | 用途 |
| --- | --- | --- | --- |
| 页面标题 | 17 / 24 | 600 | Topbar 主标题 |
| 卡片标题 | 13.5 / 20 | 600 | 分组标题 |
| 正文 | 13 / 20 | 400 | 列表、说明 |
| 辅助 | 11.5 / 17 | 400 | 元信息、路径 |
| 数字强调 | 26 / 32，等宽，`tabular-nums` | 600 | 连接码、速度 |
| 微标签 | 10.5 / 14，字距 0.06em | 500 | "连接码""已连接" |

### 2.3 间距、圆角、描边

- 间距基数 4：4 / 8 / 12 / 16 / 20 / 24 / 32。
- 卡片圆角 12；按钮/输入框 8；徽标/开关 999。
- 描边统一 1px `--line`；不使用粗边框。卡片阴影 `0 1px 2px rgba(25,27,30,.04)`，弹窗 `0 24px 60px -24px rgba(25,27,30,.4)`。
- 不使用彩色渐变、玻璃拟态、大面积阴影。唯一渐变用于进度条进行中的斜纹动画。

### 2.4 图标

- 16px 线性图标，1.5px 描边，圆头端点；与文字基线对齐。
- 关键动作优先"图标 + 文字"，纯图标按钮必须有 tooltip。
- 应用图标：抽象"桥 + 数据流"，玉青色底，白色双弧线。

### 2.5 动效

| 场景 | 时长 | 曲线 |
| --- | --- | --- |
| 页面切换 | 160 ms 淡入 + 4px 上移 | ease-out |
| 弹窗 | 180 ms scale .98 → 1 + 淡入 | cubic-bezier(.2,.8,.2,1) |
| 进度条 | 数值 300 ms 插值 | linear |
| 进行中条纹 | 1.2 s 循环 | linear |
| Toast | 进入 180 ms，停留 2.4 s | ease-out |

遵循 `prefers-reduced-motion`：关闭条纹与位移动画，仅保留透明度变化。

| 区域 | 规格 |

## 4. 导航与角色

- 侧栏顶部是 Logo + 产品名 + 角色徽标（源端玉青 / 目的端靛蓝）。点击徽标可切换角色。
- 源端导航：**共享空间**、传输记录、已连接设备、安全与信任、设置。
- 目的端导航：**连接源端**、同步任务（进行中带数量徽标）、历史记录、安全与信任、设置。
- 当前项：白底 + 1px 描边 + 轻阴影 + 玉青/靛蓝图标；非当前项 hover 为 `rgba(255,255,255,.6)`。
- 侧栏底部固定本机卡片：主机名、当前 IP、服务状态点。点击进入"关于本机"。

### 5.3 添加共享文件夹（弹窗 560）

1. 文件夹：路径输入框（只读）+ "浏览…" 按钮；选中后立即后台扫描，显示"已扫描 2,341 个文件 · 18.6 GB"（扫描中显示骨架与进度）。
2. 显示名称：默认取文件夹名，可改。
3. 权限说明：固定文案"对方只能读取此文件夹，无法修改或删除本机文件。"
4. 排除规则：默认规则以 chip 展示（`.git`、`node_modules`、`*.tmp`、`~$*`、`$RECYCLE.BIN`），可"编辑"打开规则编辑器。
5. 高级（折叠）：包含隐藏文件、单文件大小上限、允许同步符号链接。
6. 底部：取消 / **添加并共享**（源端玉青）；路径重复或与已有共享目录嵌套时，输入框下方红字提示。

### 5.10 设置

## 7. 文案与异常

**语气**：短句、说结果、给出下一步。不用"错误码 0x80070005"作为主文案。

| 场景 | 文案 |
| --- | --- |
| 服务未启动（源端） | 共享服务未开启。开启后，另一台电脑才能发现这台电脑。 |
| 无设备（目的端） | 没有发现可连接的电脑。确认两台电脑在同一网络，或直接输入对方的 IP 地址。 |
| 连接码错误 | 连接码不正确，还可以尝试 4 次。连接码 10 分钟内有效。 |
| 连接码过期 | 连接码已失效。请让源端刷新后重新输入。 |
| 连接被拒绝 | 对方拒绝了这次连接。如果这是你的设备，请在源端点击"允许连接"。 |
| 校验码不一致 | 校验码不一致，连接已中止。请确认两台电脑连接的是同一网络，并重试。 |
| 保险库/索引损坏 | 本地同步记录损坏，已重建索引。未完成的文件会重新校验。 |
| 磁盘不足 | 磁盘空间不足（还需 3.2 GB）。任务已暂停，释放空间后可继续。 |
| 文件名非法 | 3 个文件名在 Windows 上无效，已自动重命名。查看报告 |
| 源文件已变化 | 「品牌规范.pdf」在传输过程中被修改，将重新传输。 |
| 网络中断 | 连接中断，正在重连（第 2 次，最多 5 次）。已传输部分不会丢失。 |
| 完成 | 同步完成。2,341 个文件已校验，用时 4 分 12 秒。 |

## 9. 可访问性与平台细节

- 所有交互元素有可见焦点环（2px 角色色 + 2px 偏移），Tab 顺序与视觉顺序一致。
- 状态不只靠颜色：状态点 + 文案 + 图标三重表达；进度条有 `aria-valuenow`。
- 对比度：正文 `#191B1E` on `#FFFFFF` = 16.9:1；辅助文字 `#7B8087` = 4.6:1；按钮文字 ≥ 4.5:1。
- 弹窗使用 `role="dialog" aria-modal`，打开时焦点进入首个可操作项，关闭后归还触发元素。
- macOS：使用系统红绿灯与 Vibrancy 可选；Windows：Mica 可选，但默认不使用透明效果以保证可读性。
- 高 DPI：图标使用 SVG，1px 描边在 2x 下保持 1px 物理像素。
